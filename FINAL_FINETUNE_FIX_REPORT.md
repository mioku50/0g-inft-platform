## 🎯 **ВЫПОЛНЕННЫЕ ЗАДАЧИ**

### ✅ **1. Анализ проблемы**
- **Проблема:** Проект всегда использовал `broker.ledger.addLedger()` для депозита
- **Причина:** `addLedger()` создает новый аккаунт, но если аккаунт уже существует, нужно использовать `depositFund()`
- **Решение:** Добавить проверку существования аккаунта и использовать правильный метод

### ✅ **2. Исправление логики депозита**
**Файл:** `web/lib/compute/broker.ts`

**ДО (неправильно):**
```typescript
// ❌ Всегда создавал новый аккаунт
const value = ethers.parseEther(amountEth)
const tx = await broker.ledger.addLedger(value)
```

**ПОСЛЕ (правильно):**
```typescript
// ✅ Проверяем существование и используем правильный метод
const amountOG = parseFloat(amountEth)  // SDK ожидает число в OG

let hasExistingAccount = false;
try {
  account = await broker.ledger.getLedger();
  hasExistingAccount = true;
} catch (error) {
  // Аккаунт не существует
}

if (hasExistingAccount) {
  await broker.ledger.depositFund(amountOG)  // Для существующих
} else {
  await broker.ledger.addLedger(amountOG)    // Для новых
}
```

### ✅ **3. Ключевые открытия о 0G SDK**
1. **Типы данных:** SDK ожидает `number` в OG (0.005), не `BigInt` в wei
2. **Методы:** `depositFund()` и `addLedger()` не возвращают транзакцию
3. **Структура:** `ledgerInfo[0]` - баланс, `ledgerInfo[1]` - заблокированный
