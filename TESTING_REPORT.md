## Анализ проблемы с депозитом

### Возможные причины:
1. **Не все места исправлены** - возможно остались вызовы с `{ value: bigint }`
2. **Кеширование кода** - сервер может использовать старую версию
3. **Другая ошибка в SDK** - проблема может быть глубже в цепочке вызовов

### Исправления, которые были сделаны:

#### В `web/lib/compute/fine-tune-service.ts`:
```typescript
// Было:
{ value: toWei(amount) }

// Стало:  
amount  // SDK expects ETH amount as string
```

#### В `web/lib/compute/broker.ts` (2 места):
```typescript
// Было:
{ value }

// Стало:
ethers.formatEther(value)  // SDK expects ETH amount as string
```
