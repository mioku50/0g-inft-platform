**Симптомы:**

## 🤔 ВОЗМОЖНЫЕ ПРИЧИНЫ

### 1. 🎭 Проблемы с React/Next.js
- **Hydration issues** - компонент может не быть полностью гидратирован
- **Event propagation** - события могут блокироваться
- **State issues** - состояние может быть некорректным

### 2. 🌐 Проблемы с браузером
- **JavaScript отключен** - маловероятно, но возможно
- **Console фильтрация** - логи могут фильтроваться
- **Network tab** - запросы могут не отображаться

### 3. 🔄 Проблемы с состоянием
- **datasetFile** может быть null
- **isUploading** может блокировать выполнение
- **Disabled состояние** кнопки
