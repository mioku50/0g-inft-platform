## 🚀 **ИНСТРУКЦИИ ДЛЯ ТЕСТИРОВАНИЯ**

### **Шаг 1: Откройте консоль браузера**
1. Откройте страницу Fine Tune
2. Нажмите F12 (Developer Tools)
3. Перейдите на вкладку "Console"

### **Шаг 2: Выберите файл датасета**
1. Нажмите "Choose File"
2. Выберите файл (.json, .jsonl, или .txt)
3. **Проверьте в консоли лог:** `[File Select] 📁 File selected:`

### **Шаг 3: Нажмите Upload Dataset**
1. Нажмите кнопку "Upload Dataset"
2. **Проверьте в консоли логи:**
   - `[Button Click] 🎯 Upload Dataset button clicked!`
   - `[uploadDataset] 🚀 Starting upload process...`

### **Шаг 4: Анализируйте результат**
- ✅ **Если видите логи** → функция работает, проблема в другом месте
- ❌ **Если логов нет** → JavaScript заблокирован или ошибка в коде

## 💡 **ДОПОЛНИТЕЛЬНАЯ ИНФОРМАЦИЯ**

### **Логика работы Upload Dataset:**
1. **Выбор файла** → сохраняется в состоянии `datasetFile`
2. **Нажатие кнопки** → вызывается функция `uploadDataset()`
3. **Загрузка** → файл отправляется в `/api/compute/fine-tune/upload`
4. **Обработка** → файл загружается в 0G Storage
5. **Результат** → получаем `rootHash` и `dataSize`

### **Отличие от Start Fine Tune:**
- **Upload Dataset** → только загружает файл в 0G Storage (НЕ требует кошелек)
- **Start Fine Tune** → запускает обучение (ТРЕБУЕТ подключение кошелька и подпись транзакции)

**0G Storage Private Key** используется на сервере для загрузки файлов, пользователь его не видит.
